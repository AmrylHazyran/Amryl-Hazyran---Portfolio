# Personal Portfolio & Blog Page

## 📌 Project Description
This repository contains my personal portfolio and blog website, built as an individual project for the course **CSD 34203: Special Topics in Software Development** at **Universiti Sultan Zainal Abidin (UniSZA)**. 

The website serves as a professional portfolio showcasing my academic achievements, technical skills, and projects as a Computer Science graduate specializing in Computer Network Security. It features a custom, aesthetic **red and black dark-themed design** reflecting a cybersecurity/tech vibe.

---

## ✨ Features
*   **Responsive Layout:** Fully optimized for desktops, tablets, and mobile devices.
*   **Aesthetic Theme:** Dark mode design utilizing a high-contrast red and black color scheme.
*   **About Section:** Comprehensive overview of my educational background and core tech competencies.
*   **Project Showcase / Blog:** 2-3 sample posts/cards displaying key academic projects (e.g., Digital Forensics Tool, Secure Network Topology).
*   **Interactive Contact Form:** A functional front-end form with JavaScript validation for user interaction.

---

## 🛠️ Technologies Used
*   **HTML5:** Structural layout of the portfolio and blog.
*   **CSS3:** Custom styling, typography, responsive media queries, grid systems, and hover animations.
*   **JavaScript (ES6):** Interactivity for form handling and event handling.
